## 기간
- 2025년 7월 7일 ~ 9월 25일 (2개월)
- 2025년 2월 4일 ~ 7월 26일 (5개월)

## 목적
야구의 역동적인 긴장감을 가상 현실에서 실체화하기 위해 프로젝트를 시작했습니다. <br>
VR 기기의 특성을 극대화하여 실제 마운드와 타석에서의 현장감을 구현하고, 정교한 물리 로직을 통해 유저가 직접 경기의 핵심 루프를 경험하게 하는 데 중점을 두었습니다.
