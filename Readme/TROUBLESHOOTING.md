# 트러블 슈팅
프로젝트 개발 중 발생한 주요 기술 이슈와 해결 과정을 정리한 문서입니다.

---
## 주자

### 문제
주자가 베이스 사이에 있을 때 데이터가 덮어씌워지는 것을 방지하고자 queue 배열 구조를 선택했으나 특정 구간에 두 명의 주자가 존재할 경우 가장 앞에 있는 주자의 정보만 접근이 가능하고 뒤 따르는 주자의 데이터는 개별적으로 제어할 수 없는 구조적 한계를 확인 했습니다.

### 해결 방안
데이터 자료구조를 queue[4]에서 List로 변경했습니다. 
 
### 결과
자료구조 변경 후 주자 간 데이터 간섭으로 발생하던 버그를 근본적으로 해결했으며, 향후 복잡한 진루 상황 (아웃, 수비)에도 유연하게 대응할 수 있는 안정적인 알고리즘 구조를 설계할 수 있게 됐습니다.
